# 나의 사주 달력 v1.8

## 이번 버전의 변화
- 06 / PERSONAL READING의 어려운 전문 용어를 줄이고 아이도 이해하기 쉬운 말과 생활 속 예시로 풀이합니다.
- 달력에서 선택한 **하나의 연도만** 전체·직장(이직/퇴사/창업/승진)·재물·학업·건강/안전/대화 해설에 사용합니다.
- 각 분야는 `한 줄로 말하면 → 쉽게 설명해 드릴게요 → 궁금한 사람만 보기(해석 근거)` 순서로 보여 줍니다.
- 기존의 올해·내년 동시 표시와 올해/내년 전환 버튼을 없앴습니다.

## 연도 변경 방법
1. 출생정보 입력 후 **사주 분석하기**를 누릅니다.
2. 04 / 월간 일진 달력의 **풀이할 연도**에 1900~2100년 사이의 숫자를 직접 입력하고 **연도 이동**을 누릅니다.
3. 06 / PERSONAL READING에 해당 연도의 풀이 하나만 나타납니다. 달력에서 월을 옮겨 연도가 바뀌어도 자동으로 갱신됩니다.

## 기존 기능
기본 만세력·오행 결과, 시간 보정 비교, 달력과 조화/재물 상징일, 월별 선 그래프, 상징 숫자 5그룹, 모바일 선택 다이얼, 분석 진행 안내는 유지합니다.

## 설치 방법
- **단일 HTML**: PC에서 `saju_calendar_standalone_v1_8.html`을 열어 사용합니다.
- **ZIP**: 압축을 풀고 `index.html`, `style.css`, `js/`, `data/`, `icons/`, `sw.js` 등을 **모두** GitHub Pages 저장소에 업로드해 기존 파일을 교체합니다. 화면에 v1.8이 표시되는지 확인합니다.

## 주의
명리학의 십성과 오행, 간지 관계에 관한 전통적 해석을 이해하기 쉽게 풀어 쓴 참고용 콘텐츠입니다. 실제 진로·재물·건강·사고를 예측하지 않습니다. 전문 대운·격국·용신 판정은 구현되지 않았으며, 역법은 1900~2100년 전체 공식 자료와 전수 대조된 상태가 아닙니다.
