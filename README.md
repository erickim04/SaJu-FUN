# 나의 사주 달력 v1.6 — 조화 상징일·재물 상징일 달력 표시

## 추가 기능
- **조화 상징일:** 사주 일간과 해당 날짜 천간이 **천간 오합**이거나, 사주 일지와 날짜 지지가 **육합**인 날짜를 표시합니다. 해당 날짜를 누르면 어떤 조건이 맞았는지 설명합니다.
- **재물 상징일:** 사주 일간 기준 날짜 천간의 십성이 **정재 또는 편재**인 날짜를 표시합니다. 이는 재성이라는 전통적 상징을 뜻하며 실제 재물이나 수입을 예측하지 않습니다.
- 같은 날짜에 두 가지 표식이 동시에 나올 수 있습니다.
- 달력 상단에 월별 표식 개수를 제공하며, 출생정보/시간 보정 방식/조회 월 변경 시 갱신됩니다.
- 출생정보를 분석하기 전에는 개인 표식을 노출하지 않습니다.
- 월간 흐름 그래프, 분야별 풀이, 숫자 상징 5그룹, 모바일 다이얼 입력 등의 기존 기능을 유지합니다.

**중요:** 표시가 없는 날을 나쁜 날로 해석하지 않으며, 표식은 전통 명리학에서 선택한 일부 규칙의 계산 결과일 뿐 미래 사건, 금전적 결과 또는 좋은 일이 발생할 확률을 뜻하지 않습니다.

## 배포
v1.6 ZIP 압축을 풀고 파일 **전체**를 기존 GitHub Pages 저장소에 업로드해 교체하세요. `sw.js` 캐시 버전도 갱신되어 있습니다. 단일 HTML은 PC에서 파일을 직접 열어 실행할 수 있습니다.

# 나의 사주 달력 v1.6 — 월간 흐름 그래프 + 분야별 상세 해설

## 신규 기능
1. **선 그래프:** 조회 월(달력 화살표로 변경)의 날짜별 일진, 개인 일간 십성 및 지지 관계를 적용하여 월 평균 0의 **상대적 전통 상징 점수**를 표시합니다. 선 위 날짜를 선택하거나 달력의 날짜를 클릭하면 상징 해석과 계산 근거를 갱신합니다.
2. **올해·내년 총운세:** 실행 시점의 한국 연도와 다음 연도의 세운 간지/일간 십성을 기준으로 **한 줄 총평 + 세부 설명**을 제공합니다.
3. **직장운:** 이직·퇴사·창업·승진 각 항목의 한 줄 총평과 상세 해설을 제공합니다.
4. **재물운·학업운·주의사항:** 재물, 학업, 건강 관련 주의, 일상 안전, 구설·대인관계 항목의 한 줄 총평과 세부 해설을 제공합니다.
5. **기존 기능 유지:** 모든 입력란 직접입력+다이얼, 분석 로딩, 표준시 3방식 비교, 오행 그래프, 만세력 달력, 상징 숫자 5그룹.

## 중요 안내
- 선 그래프 점수는 앱이 정의한 규칙으로 계산한 **월내 상대 순위**입니다. 실제 운세의 확률이나 객관적인 좋고 나쁨, 건강·사고 발생 위험을 뜻하지 않습니다.
- 해설은 올해 세운 간지와 일간의 십성, 일지 충 등을 근거로 전통적 의미를 풀어낸 문구입니다. 아직 구현하지 않은 대운·격국·용신을 반영했다고 주장하지 않습니다.
- 기존처럼 양력 1900~2100 / 음력 1900~2050이며 절기표 공식 전수 검증이 완료되지 않았습니다.

## 스마트폰 배포
ZIP 파일 압축을 푼 **내용물 전체**를 GitHub 저장소에 업로드하고 Commit 하세요. `index.html`, `style.css`, `js`, `data`, `sw.js` 모두 교체해야 합니다. 새 버전이 표시되지 않으면 브라우저에서 새로고침한 후 상단 **v1.6** 표시를 확인하세요.

# 나의 사주 달력 v1.6 — 분석 진행 표시·결과 확인 기능 보강

- 출생정보 입력 후 사주 분석하기를 누르면 **사주 분석 중** 스피너와 안내 문구가 표시됩니다.
- 결과 계산 후 입력창 바로 아래에 **분석 완료 / 분석 결과 바로 보기 ↓** 버튼이 표시됩니다.
- 계산 오류는 입력창 위 오류 메시지에 표시하며 원인을 숨기지 않습니다.
- 부가 기능에서 오류가 나더라도 핵심 사주 원국 출력은 별도로 유지하고 기본값을 보여줍니다.
- 스마트폰의 HTML 미리보기에서 스크립트가 차단되어 앱이 실행되지 않는 경우 안내 문구가 남습니다. 이 경우 Chrome·Safari 브라우저 또는 GitHub Pages 배포 주소에서 실행해야 합니다.
- 새 버전 확인: 상단 `v1.6` 및 하단 `베타 v1.6` 문구가 보여야 합니다.

# 나의 사주 달력 v1.6 — PC·모바일 직접 입력 + 다이얼 겸용

## v1.6 수정
- 모든 10개 출생정보 입력 항목(양/음력, 출생연도, 월, 일, 윤달, 대운용 성별 분류, 시도, 도시, 출생 시, 출생 분)은 **입력칸에 직접 쓰거나 옆 ⌄ 버튼을 눌러 다이얼을 스크롤**할 수 있습니다. 모바일과 PC가 동일한 방식입니다.
- 실제 내부 계산은 기존 원본 선택값으로 실행합니다. 입력한 텍스트는 계산 전에 해당 선택 항목의 정확한 값으로 변환·검사합니다.
- 입력값이 틀리면 해당 칸을 빨갛게 표시하고 **사주 분석하기**를 누를 때 오류를 상단에 보여줍니다.
- 출생 시·도 변경 시 해당 지역의 도시 목록이 자동 갱신됩니다. 날짜도 출생 월과 양음력 여부에 맞춰 갱신됩니다.
- 구버전 캐시 문제를 줄이기 위해 스크립트 버전을 명시하고 서비스워커를 네트워크 우선으로 변경했습니다.

## PC에서 사용
- `index.html`을 더블클릭하여 실행하거나 별도 제공하는 단일 HTML 파일을 사용합니다.
- 생년월일 등을 직접 입력하거나 오른쪽 ⌄ 버튼을 눌러 다이얼에서 선택합니다.
- `사주 분석하기`를 누르면 화면의 **사주 원국**, **오행 분석**, **오행 상징 숫자**가 표시됩니다.
- **출생 분**은 출생시간을 `모름 / 미입력`으로 지정하면 사용할 수 없습니다.

## 스마트폰 또는 GitHub Pages에서 사용
- ZIP 압축을 해제한 **내용물 전체**를 GitHub 저장소에 업로드하세요. 기존 `index.html`, `style.css`, `js`, `data`, `sw.js`를 반드시 모두 교체해야 합니다.
- `Settings → Pages`에서 배포 주소로 접속하세요.
- 기존 홈 화면 앱에 이전 버전이 남으면 브라우저에서 새 주소를 열어 한 번 새로고침하세요. 그래도 문제가 발생하면 옛 홈 화면 아이콘을 삭제하고 새 주소로 재설치하세요.
- GitHub의 기존 저장소에 ZIP 파일 하나만 올리면 앱이 갱신되지 않습니다.

## 참고
- 양력 출생연도 1900~2100을 목표로 지원합니다. 음력은 1900~2050년 내장 변환 자료를 사용합니다.
- 1900~2100년 절기표는 천문 계산 기반 추정값으로 공식 역법 자료와 전수 검증되지 않았습니다.
- 명리학 풀이 및 오행 상징 숫자는 전통적 상징/개인 감상용이며 실제 행운이나 금전적 결과를 예측하지 않습니다.
- 상세 용신·격국·대운 해설은 아직 미구현된 기능입니다.
- 출생정보는 사용자가 저장에 동의한 경우에만 브라우저 내부에 저장됩니다.
