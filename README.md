# 나의 사주 달력 v1.9

## 변경 사항
- 요청에 따라 **06 / PERSONAL READING(연간 종합 사주풀이)** 메뉴와 화면을 완전히 삭제했습니다.
- 날짜별 달력, 오행·십성 기초 정보, 운의 흐름 선 그래프, 조화·재물 상징일, 숫자 조합 5그룹은 유지합니다.
- 04번 달력의 연도 입력은 '조회할 연도'로 변경했습니다. 달력·그래프·숫자 조합을 조회 연도에 맞춰 변경합니다.
- 남은 섹션은 계산 기준 06번, 오행 상징 숫자 07번으로 번호를 정리했습니다.
- 관련 `personalReading.js` 스크립트와 호출을 제거했습니다.

## 사용법
- 단일 HTML 파일: `saju_calendar_standalone_v1_9.html`을 PC의 Chrome/Edge 등 브라우저로 엽니다.
- 스마트폰: ZIP 압축을 풀고 **모든 파일**을 GitHub Pages 저장소에 업로드한 후 페이지를 새로고침합니다.
- 기존 캐시가 남은 경우, 새 버전 v1.9가 표시되는지 확인하세요.

## 남아 있는 기능
1. 양·음력, 시·도·도시, 출생시간 직접 입력 및 다이얼
2. 3가지 시간 보정 기준을 비교하는 사주 원국
3. 기본 오행 분포 및 십성·지장간 기초 정보
4. 월간 일진 달력과 조화·재물 상징일
5. 선택한 월의 일별 흐름 선 그래프
6. 시간대·계산 출처·한계 안내
7. 1~45 오행 상징 숫자 5그룹 × 6개

주의: 사주 해석 및 숫자 조합은 전통적 상징적 참고 자료이며 미래나 금전적 결과를 예측하지 않습니다. 공식 역법 자료와 전체 연도 전수 검증된 버전은 아닙니다.
