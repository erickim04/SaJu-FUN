07 / SOURCES & METHOD

계산 기준과 주의사항

역법 계산

양력 1900~2100, 일진 60갑자 순환, 태양 황경 계산으로 생성한 절기표를 사용합니다. 절기표는 공식 월력과 전수 대조한 자료가 아닙니다.

음력 입력

한국식 음력 월 시작 자료는 1900~2050년만 제공합니다. 2051~2100년에는 양력 입력을 사용하세요. 한국천문연구원의 공식 값과 차이가 있을 수 있습니다.

출생시간

Asia/Seoul 역사적 법정 시간대를 적용합니다. 지방평균태양시와 진태양시(균시차 근삿값)를 비교하고, 서머타임 중복/누락 시각은 안내합니다.

일주와 자시

일주가 00시에 바뀌는 방식과 23시에 바뀌는 방식을 별도로 표시합니다. 연주·월주는 절입 순간의 시간 순서를 따릅니다.

전통적 해석

오행·십성의 월간 상대 흐름과 연간 풀이 모두 명리학의 상징적 설명입니다. 선 그래프는 월 평균 0의 자체 가중 규칙이며 재물·건강·사고·미래 사건의 가능성을 예측하지 않습니다.

개인정보

입력값은 서버로 전송하지 않습니다. 정보 저장을 선택한 경우에만 현재 브라우저의 localStorage에 저장됩니다. 저장을 해제하면 해당 기록을 삭제합니다.

자료 및 기술 근거 한국천문연구원 음양력 API · 특일·24절기 API · Korean Lunar Calendar (MIT) · Swiss Ephemeris 천문 계산 결과(사전 생성) · IANA Asia/Seoul 시간대 데이터
08 / FIVE ELEMENT SYMBOLS

나의 행운·재물 상징 숫자

사주 원국과 조회 월의 간지·오행을 상징적 숫자 규칙에 연결하여 1~45에서 6개씩, 5그룹을 만듭니다.

✧
출생정보를 입력하고 사주 분석하기를 누르면 숫자 6개 × 5그룹을 한 번에 표시합니다.

숫자 구성 원칙

각 그룹에는 목·화·토·금·수에 해당하는 숫자를 하나씩 넣고, 일간과 월운의 오행을 고려한 강조 오행 숫자를 하나 더 배치합니다. 총 30개 숫자는 그룹 내부와 그룹 사이에서도 서로 중복되지 않습니다.

숫자 끝자리와 오행의 대응은 앱에서 정의한 상징적 확장 규칙입니다. 실제 행운이나 재물 획득 가능성을 높이는 번호라는 뜻은 아닙니다.
